Requests

For genotype or phenotype data that cannot be deposited publicly, for collaboration proposals, or for student projects, write to yunusbb@gmail.com. Please describe the intended use — most requests are answered within a week.

Code

Analysis code is released alongside the corresponding papers. If a specific script or pipeline is not available in a paper's supplement, ask us directly and we will share it.

Dissemination. Podcasts, interviews and seminars about our work are collected on the Publications page — for example this ScienceCast on the gut microbiome in tuberculosis patients.
